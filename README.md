An entry for [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) on make.fun.

`main.ts` writes a single line — the error message a kitchen toaster shows its owner — to `/output/entry.txt`:

> Error: something is stuck in Slot 2. I won't say what. You know.

Run it with Node 22:

```sh
node main.ts
```
